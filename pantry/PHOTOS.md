Ты выбираешь фотографии к идеям блюд для моей страницы «Еда». Ниже — список блюд, и для каждого несколько файлов-кандидатов. Открой каждый файл инструментом Read и посмотри на него.

Ответ — **только JSON**, без markdown и пояснений, объект вида:

```
{"Название блюда ровно как в списке": "имя-файла-кандидата.jpg", "Другое блюдо": null}
```

Как выбирать:
- **Сначала верность.** На фото должно быть узнаваемо то самое блюдо или очень близкое. Паста вместо грибов, фаршированный перец вместо сырников, банка соуса вместо пельменей — это брак, даже если снимок красивый.
- **Потом аппетитность.** Из подходящих бери тот, где еда выглядит вкусно: тёплый свет, крупный план, аккуратная подача. Отбрасывай тусклые, пересвеченные, снятые со вспышкой на клеёнке, с грязной посудой и посторонним хламом в кадре.
- Горизонтальные кадры лучше вертикальных: карточка обрезает по ширине.
- Если ни один кандидат не годится — поставь `null`. Пустая карточка лучше, чем фотография не того блюда: подпись обещает иллюстрацию к блюду, а не случайную еду.
- Ключи объекта — названия блюд ровно как в списке, слово в слово. Значения — только имя файла, без пути.
