## Инвест (`invest.html`, `scripts/invest.py`, `/api/invest`, 06.10.2026)

Страница стратегии из `~/workspace/invest` (на mini — `~/invest`, launchd `ru.invest.morning/evening`): режим
прогона (песочница / реальный счёт / оба, рубильник STOP), стоимость счетов против «лежало бы под ключевую»,
позиции, дивидендный план и последние заявки. **Сама страница в T-Invest не ходит и токенов не знает** — читает
только файлы прогона: `data/forward.csv`, `data/orders.csv`, `data/keyrate.csv` и снимок `data/state-<mode>.json`,
который `invest plan --execute` пишет после каждого прогона (позиции, план, что исполнено). Снимок появляется
только после первого прогона по счёту — до него карточка счёта говорит «прогонов ещё не было». Каталог стратегии —
`INVEST_DIR`, по умолчанию `~/invest`, иначе `~/workspace/invest`; режим — `~/.config/tinvest/mode`. Советов здесь
нет, как и на «Тратах»: только то, что стратегия делает по своим правилам. Уведомления «Инвест» открывают эту
страницу (`page: "invest"` в `notify.py`); в приложении она — строка «Инвест» в «Ещё».

«Последние действия» (09.10.2026) — лента прогонов сразу под счетами: каждая строка `forward.csv` с заявками
этого прогона, **включая «ничего не делали»** — иначе по странице не понять, был ли сегодня прогон. Заявка
относится к прогону, если она не раньше чем за `RUN_WINDOW` = 20 мин до его строки (строка пишется в конце
прогона, а повторы и лимиты API растягивают его); заявка вне окна (ручной тест) — отдельной строкой «вручную».
Статус в `orders.csv` — голый `FILL`, без префикса `EXECUTION_REPORT_STATUS_`.

## Исполнитель стратегии и Codex (30.10.2026)

Утренний и вечерний launchd-агенты запускают `~/invest/scripts/daily.sh` → `uv run invest plan --execute`.
Это Python-стратегия с фиксированными правилами, без вызовов Claude или другой LLM. Переход фоновых
советов BoW на Codex (`docs/ai.md`) не меняет правила, режим счёта, рубильник STOP и расписание инвеста.
