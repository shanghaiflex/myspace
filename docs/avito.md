# Слежка за Авито удалена

21.10.2026 по просьбе пользователя слежка за Авито убрана из BoW: блок на главной, уведомления,
API, страница проверки и скрипты прогона удалены. Агент `cc.bodywithoutorgans.avitowatch` на mini
выгружен, его plist убран из `~/Library/LaunchAgents`, отдельный браузер слежки закрыт.

Личные слежки, история и plist сохранены вне сайта на mini в `~/.avito-watch/retired-20261021/`.
Исключения для прежних путей в `.gitignore` и `scripts/deploy.sh` оставлены, чтобы случайно не
опубликовать личные данные и не стереть их при выкладке со старой копии.
