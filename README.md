# Movies

Личный каталог фильмов: что посмотрел (с оценками), что хочу посмотреть, что смотрю сейчас.

```
./serve.sh            # → http://localhost:8787
```

Вторая страница, «Миксы»: утренний плеер, случайный микс из коллекции и кнопка «Следующий».
Источники: SoundCloud, YouTube, Mixcloud, NTS. Ссылки добавляются прямо на странице (вставить в поле или Cmd+V).

Оценка, статус, заметка и удаление редактируются прямо в карточке фильма на сайте.
Добавление новых фильмов — через Claude Code (см. `CLAUDE.md`), под капотом `scripts/movies.py`.
На другом компьютере: `git clone`, `./serve.sh`. Нужен только Python 3.
Синхронизация между компьютерами — обычный `git pull` / `git push`.
